## Key Concepts Covered

1. **Test Design Workflow:** Load context → Risk/Testability assessment → Coverage planning → Test design document (design before code)
2. **Risk = Probability × Impact;** Login = P0, Tooltip = P3; testability = can we test it easily?
3. **Coverage Planning:** Unit (isolated), Integration (components+DB/API), E2E (full flow); P0 = Unit+Int+E2E, P1 = Int+E2E, P2 = Int or E2E, P3 = manual/skip
4. **Test Priorities Matrix:** P0 all levels ✅, P1 Unit+Int+E2E, P2 Int+Manual, P3 Manual; target 100% P0, 80% P1, 50% P2, 20% P3
