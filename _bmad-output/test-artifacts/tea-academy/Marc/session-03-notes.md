## Key Concepts Covered

1. **Fixture Architecture:** Composable fixtures, DRY, mergeTests, automatic teardown, type-safe
2. **Network-First:** Intercept/route before action → no race conditions, deterministic, fast
3. **Data Factories:** createEntity(overrides), no hardcoded data, self-documenting
4. **Step-File Architecture:** Micro-files, just-in-time loading, sequential, state tracking, continuable
