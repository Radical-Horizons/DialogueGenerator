## Key Concepts Covered

1. **Test Review:** 5 dimensions = Determinism, Isolation, Assertions, Structure, Performance; overall score = average 0–100.
2. **Trace Workflow:** Load context → Discover tests → Map criteria → Analyze gaps → Gate: GREEN (ship) / YELLOW (assess) / RED (block if P0 gaps).
3. **Quality Metrics:** Track P0/P1 coverage %, flakiness rate, execution time, determinism score. Avoid vanity metrics (line coverage, test count, file count).
