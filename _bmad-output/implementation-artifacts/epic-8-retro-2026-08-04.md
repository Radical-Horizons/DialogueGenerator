## Ce qui s’est bien passé

1. **Specs figées comme contrat** — Always / Ask First / Never ont permis de renegocier le PRD (lieu/thème, filtres serveur, statut éditorial) sans dériver le MVP.
2. **Extension plutôt que duplication** — surface unique `useDialogueListData` + listing Unity ; services métier dédiés (collections, index, metadata, batch) branchés au container.
3. **Réemploi Epic 1 / 4** — validation batch = graphe + schéma + lore existants ; génération batch = orchestrateur + `connectNodes` côté front (règle produit respectée).
4. **Seuils sync / job** — pattern clair 20 (validate) / 10 (generate) ; polling app-level (miroir génération → validation) pour toast de fin hors page.
5. **Revue Always en fin de branche** — écarts détectés (toast 8.8, progress j/k, focus deep-link, sprint-status) corrigés avant clôture, pas laissés en « review » flou.
6. **Sécurité batch** — jobs isolés par owner (guest `sid`) ; estimation coût multipliée par le nombre de parents.

## Défis et zones de croissance

1. **Drift PRD vs specs** — `epic-08.md` / `epic-8-context` parlent encore pagination+filtres+tri **serveur**, lieu/thème, SSE obligatoire. Le livré suit les specs figées (client + FTS quand `q`, polling). Risque de confusion pour une future revue PRD-only.
2. **Jobs async vs cycle de vie UI** — premier passage 8.8 : polling dans le hook de la liste → toast perdu à la navigation. Pattern store app-level à généraliser dès le premier job UI.
3. **Deep-link multi-éditeurs** — focus branché d’abord pour le graphe (`useDialogueLoader`) alors que le CTA bibliothèque ouvre l’éditeur Unity linéaire. Toujours vérifier le **chemin réel** d’ouverture.
4. **Process sprint-status** — plusieurs stories restées en `review` après implémentation `done` dans les specs ; alignement tardif.
5. **Perf listing / coûts** — `get_all_dialogues_costs` encore global (deferred) : OK MVP, frein potentiel à 1000+ dialogues.
6. **FTS rebuild** — pas de shadow/swap ni reset `running` stale au boot (deferred) : acceptable mono-processus, fragile en crash mid-rebuild.
