## Défis et zones de croissance

### 1. `useNarrowInlineSize` et ref montée tardive (17.7 → 17.8)

**Symptôme :** hook sur `Dashboard` alors que la ref n’existe qu’après activation d’onglet → `ResizeObserver` jamais attaché → tests bloqués ~1h.  
**Correctifs :** callback ref (17.8), extraction **`DialogueEditionTabContent`**, mocks dédiés.  
**Cause systémique :** mesurer un conteneur dont le DOM n’est pas monté au premier render.

### 2. RTL / jsdom vs preuve navigateur

- Alignement ±2px, touch réel, resize colonne : jsdom insuffisant.
- Revues récurrentes demandent **preuve UI** (`npm run dev` + checklist skill).
- **Apprentissage :** marquer explicitement dans les stories « preuve UI obligatoire » dès qu’un AC est spatial.

### 3. File List vs git (héritage Epic 16)

- Réapparu en 17.6, 17.8 — bruit en review, pas de régression fonctionnelle.
- Checklist review à renforcer.

### 4. Cibles tactiles toolbar narrow (~32px)

- Confort desktop : **44×44px** validé (agent CDP).
- Narrow toolbar : ~32px — test **`fr119-touch`** documente « cible tactile réduite » en narrow.
- **Tension produit :** FR119 strict 44px vs densité toolbar ; documenter comme choix ou planifier harmonisation.

### 5. Dette structurelle restante

- **`GraphToolbarToolsRow.tsx`** (~646 L) — hors scope 17.9–17.11 ; prochaine découpe possible en epic dette ou story 17.x+.
- Playwright narrow combobox — backlog explicite story 17.7.
